## 만들 것
- 새 파일 `src/components/ui/MiniMap.tsx` (+ 필요하면 CSS)
- 위치: 화면 **오른쪽 위**. 다른 HUD(접속자 수, 대화 등)와 겹치지 않게 한다. **오른쪽 위에는 이미 소리 버튼이 있다**(`src/components/ui/HelpPanel.tsx:94` 안내 문구 참고). 그 아래에 놓거나 한 줄로 나란히 둔다.
- 그리는 방식: `<canvas>` 2D 또는 SVG. three.js 장면에 넣지 않는다.
- 표시할 것:
  - 원형 길, 안쪽 길(연한 선)
  - **숲속여행 산길 초입, 숲의 빈터, 오두막** (점 + 이름)
  - **내 위치와 바라보는 방향** (화살표)
- 갱신 주기: 초당 5~10번이면 충분하다(`requestAnimationFrame`에서 시간 간격으로 줄인다). React state를 매 프레임 바꾸지 않는다.
- **원형 길 밖으로 너무 멀어지면**: 내가 원형 길 바깥으로 일정 거리(예: 15m) 이상 나가면 원 안쪽 표시(빈터, 오두막, 안쪽 길)는 감추고 원형 길과 내 위치만 보인다. 기준 거리는 상수로 둔다.
- **닫기 버튼**: 지도 오른쪽 위 `×` → 지도가 접히고 **지도 아이콘 버튼**만 남는다 → 누르면 다시 펼친다. 열림·닫힘 상태는 `localStorage`에 저장한다(읽기·쓰기는 try/catch로 감싼다).
- 키보드: 지도 열고 닫기 단축키는 `N` (안 쓰는 키인지 확인. `M`은 소리, `H`는 안내다). 안내(`H`) 화면 조작표와 README 키 표에 한 줄 추가한다.
- 모바일: 크기를 줄이고(예: 120px), 오른쪽 위 다른 버튼과 겹치지 않게 한다.
