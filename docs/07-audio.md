# 07 · 절차적 사운드

## 원칙

- **외부 음원 파일을 사용하지 않는다.** 모든 소리는 Web Audio API 로 합성한다.
- **사용자 제스처 이후에만** 시작한다(브라우저 자동재생 정책).
- 야간/실내/앉음/쉬는 중/불 세기에 따라 **믹스가 천천히 변한다.**
- 소리는 분위기를 돕되 대화를 방해하지 않는다. 마스터는 컴프레서를 거친다.

## 신호 흐름

```
[바람] noise ─ lowpass ─ gain ─┐
[나뭇잎] noise ─ bandpass ─ gain ─┤
[새] oscillator/짧은 noise ─ gain ─┤
[불] brown noise ─ lowpass ─ gain ─┼─▶ master gain ─▶ compressor ─▶ destination
[발소리/장작/의자/담요/한모금] ────┘        │
                                       reverb(convolver) ─ wet gain ─┘
```

## 환경 믹스

`audio.update({ night, cabin, sitting, resting, fireIntensity })`

| 조건 | 변화 |
| --- | --- |
| 밤 | 바람·나뭇잎 감소, 새소리 거의 없음, 낮은 드론 |
| 실내 | 바람/새 감소, 불 소리 증가, 잔향 증가 |
| 앉음 | 발소리 없음, 새/바람 비중 증가 |
| 쉬는 중 | 마스터 감소, 저역 중심 |
| 불 세기 | 불 소리 게인/크래클 빈도 증가 |

## 발소리

- 표면: `grass | dirt | wood | stone`
- 짧은 노이즈 버스트 + 필터 + 엔벨로프. 달리면 간격이 짧고 세다.
- `stepAccum` 이 1.72m(걷기)/2.0m(달리기)마다 재생.
- 표면은 `groundAt().surface` 로 결정된다.

## 상호작용 사운드

| 메서드 | 트리거 |
| --- | --- |
| `footprint(surface, running)` | 이동 누적 거리 |
| `rustle()` | 풀/담요/장작 줍기 |
| `creak()` | 앉기/일어나기/침대 |
| `logDrop()` | 벽난로에 장작 |
| `sip()` | 커피/물 |
| `setMuted(bool)` | M 키/버튼 |

## 성능과 안전

- AudioContext 1개, 노드 재사용, 타이머는 `unref` 대신 명시 정리.
- 화면이 백그라운드로 가면 브라우저가 자동 suspend 할 수 있다.
- 음소거는 master gain 0 으로 처리해 그래프를 재구성하지 않는다.
- 사용자가 들어오기 전에는 어떤 노드도 만들지 않는다.
- 소리 크기는 과하지 않게 0.75 마스터에서 시작한다.

## 확장 아이디어

- 계절별 새/매미/낙엽 소리
- 거리 기반 발소리 패닝(현재는 리스너 x/z 만 사용)
- 오두막 축음기(짧은 절차 멜로디)
- 접근성: 시각적 사운드 표시(새가 날면 아이콘)
