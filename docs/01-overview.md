# 01 · 서비스 개요

## 한 줄 소개

> 같은 시간, 같은 숲을 걷는 사람들과 은은하게 연결되는 1인칭 힐링 산책.

숲속여행은 설치·튜토리얼·보상 없이 브라우저에서 바로 시작하는 3D 공간입니다.
경쟁과 임무 대신 **걷기, 앉기, 불 피우기, 창밖 보기**라는 작은 행동에 집중합니다.

## 여정

숲을 한 바퀴 도는 **원형 길**(한 바퀴 약 620m)이 있고, 그 안쪽에 빈터와 오두막이 있다.
원형 길에서 이정표가 선 갈림길로 들어가면 빈터나 오두막에 닿는다. 계속 걸으면 처음 자리로 돌아온다.

```
산길 초입 (0, 72) ── 원형 길 위, 고리 안쪽을 바라보며 시작
   │  표지판 · ← 숲의 빈터 / 오두막 → 화살표 · 그루터기 · 새소리
   │
   ├─ 왼쪽(-x)으로 약 127m ─ [숲의 빈터] 갈림길 ─▶ 숲의 빈터 (-25, -32), 반경 23m
   │                                            화덕 · 통나무 벤치 · 랜턴 · 나비 · 채팅
   │
   ├─ 오른쪽(+x)으로 약 223m ─ [오두막] 갈림길 ─▶ 숲속 오두막 (12, -152)
   │                                         ├─ 1층: 벽난로 · 흔들의자 · 무릎담요 · 주방
   │                                         └─ 2층: 침대 · 큰 창문 · 창가 좌석
   │
   └─ 고리를 따라 계속 걸으면 다시 산길 초입
```

## 핵심 경험 5가지

| 경험 | 설명 | 관련 파일 |
| --- | --- | --- |
| 걷기 | 지형을 따라 걷고, 계단으로 2층에 오른다 | `Player.tsx`, `world.ts` |
| 마주침 | 다른 접속자의 이름표와 걷기/앉기 자세를 본다 | `RemotePlayers.tsx` |
| 대화 | 빈터에서만 열리는 짧은 실시간 채팅 | `ChatPanel.tsx`, `server.mjs` |
| 쉼 | 그루터기·흔들의자·창가·침대에 앉거나 눕는다 | `InteractionSystem.tsx` |
| 온기 | 장작을 넣어 불을 키우고 담요를 덮고 차를 마신다 | `Cabin.tsx`, `FirstPersonItems.tsx` |

## 시간과 소리

- **시간**: 접속자 모두 한국 시간(`Asia/Seoul`)을 공유한다. 서버가 보낸 시각과
  클라이언트 시계의 오프셋을 보정해 태양·달·별·안개·반딧불이를 그린다.
- **소리**: 외부 음원을 쓰지 않는다. Web Audio 로 바람, 나뭇잎, 새, 발소리,
  장작, 의자, 담요, 한 모금 소리를 실시간 합성한다. 사용자가 "숲으로 들어가기"를
  누른 뒤에만 재생된다(브라우저 자동재생 정책).

## 멀티플레이어의 태도

- 40명 정원의 **작은 숲**이다. 북적이는 광장이 아니라, 같은 길을 걷는 사람들이
  가끔 마주치는 정도를 목표로 한다.
- 대화는 빈터에서만 가능하다. 산길과 오두막에서는 조용히 머문다.
- 위치·존·채팅 수신 대상·불 세기는 서버가 판정한다. 클라이언트는 화면만 그린다.

## 기술적 특징

- 3D 모델/텍스처 파일 없이 코드로 숲과 오두막을 만든다 (절차 생성).
- Next.js 와 Socket.IO 를 하나의 Node 프로세스에서 운영한다 (Render 단일 인스턴스).
- DB(Neon)는 선택적이다. 없으면 인메모리로 동작하고, 있으면 방문/채팅/불 상태를
  복원한다.
- 보안은 nonce CSP, 서버 JWT 검증, Origin 검증, 토큰 버킷, 파라미터 바인딩을
  기본값으로 둔다.
