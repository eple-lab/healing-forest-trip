```powershell

npm.cmd run lint        # ESLint (선택)
npm.cmd run build       # next build
```

빌드 시 `NEXTAUTH_SECRET` 경고는 로컬에서 정상이다(운영에서는 필수).
배포 전에는 반드시 typecheck 와 build 를 모두 통과시킨다.

커밋할 때마다 pre-commit 훅(`.githooks/pre-commit`)이 0번(개인정보) 검사를 한다. 클론마다 한 번 켠다. (BUG-06)

```powershell
git config core.hooksPath .githooks
```

막히면 `--no-verify`로 넘기지 말고 고친다. 진짜 이름이 아닌 정해진 값만 `.githooks/allow-patterns`에 예외로 적는다.

### B. 이동과 시점

- [ ] 시작 지점에서 북쪽(-z)을 바라보고, 눈앞에 가운데 길이 보인다(알림판과 시작 표지판 사이). (FEAT-02, FEAT-06)
- [ ] 가운데 길을 따라 걸으면 빈터를 지나 오두막 앞마당까지 간다. (FEAT-06)
- [ ] 시작할 때 원형 길에서 세 걸음쯤 남쪽에서 길과 표지판을 바라보고, 걷는 속도는 느긋한 산책(2.35m/초)이다. (FEAT-17)
- [ ] `W/A/S/D` 로 걷고, `↑` `↓` 로도 앞뒤로 걷는다.
- [ ] `←` `→` 로 제자리에서 돌고, `PageUp` `PageDown` 으로 위아래를 본다. 앉아 있을 때 돌려도 일어나지 않는다. 대화 입력 중에는 시점이 돌지 않는다. (FEAT-14)
- [ ] 마우스 클릭 후 포인터가 고정되고 위/아래/좌/우 시점이 된다.
- [ ] `Esc` 로 포인터 고정이 해제된다.
- [ ] `Shift` 로 달리면 빨라지고 FOV 가 살짝 넓어진다.
- [ ] 개발자 도구에서 CPU를 느리게 해도(15fps 안팎) 걷기·달리기 속도가 크게 줄지 않고, 벽·가구를 뚫지 않는다. (FEAT-05)
- [ ] 나무/오두막 벽/가구에 끼지 않고 미끄러진다.
- [ ] 경계(`x ±86`, `z -225~105`)를 벗어나지 않는다.
- [ ] 원형 길을 따라 한 바퀴 걸으면 끊김 없이 처음 자리로 돌아오고, 길 바깥쪽으로 숲이 보인다. 이음매(시작 지점)에서 길 띠가 끊기거나 무늬가 튀지 않는다. (FEAT-06)
- [ ] 원형 길의 구불거림이 예전 일자 길과 비슷하다. (FEAT-06)
- [ ] 원형 길과 두 갈림길에서 나무·바위·가구에 끼지 않는다. (FEAT-06)
- [ ] 계단을 걸어서만 2층에 오른다(순간이동 없음).
- [ ] 오두막 현관 데크 위에서 발이 데크에 잠기지 않고 나무 발소리가 난다. 데크 앞 계단 두 칸은 데크 바깥(남쪽 +z)에 있고 밟고 오를 수 있으며, 데크와 문턱 사이에서 걸리지 않는다. (BUG-10)

## 자동 회귀 스크립트

로컬 서버(`npm run dev`)가 켜져 있을 때 실행한다.

```powershell
node scripts/smoke-visual.mjs   # 랜딩/로그인/걷기/도움말/채팅/모바일 화면 + 콘솔 오류 수집
node scripts/smoke-two.mjs      # 2탭 접속·이동(players:move 배치)·즉시 퇴장 확인
node scripts/smoke-scene.mjs cabin-noon "spawn=cabin&time=13:00" up   # 장소·시간을 정해 한 장(+하늘) 찍기 (FEAT-15)
```

### 개발 모드 테스트 도구 (FEAT-15)

`npm run dev` 로 띄운 개발 모드에서만 쓸 수 있다. 배포본(`NODE_ENV=production`)에서는 패널이 없고 주소 옵션도 무시된다.

- 화면 왼쪽 아래 **DEV** 패널: [시작] [빈터] [오두막] 순간이동, [아침] [낮] [저녁] [밤] [지금] 시간 바꾸기.
- 주소 옵션: `/forest?spawn=start|clearing|cabin&time=13:00`.
  - `clearing`: 빈터 갈림길 끝에서 화덕을 본다. `cabin`: 오두막 앞마당(앞벽에서 남쪽 +z 로 11m)에서 문을 본다.
  - `time` 은 내 화면에만 적용된다(서버·다른 사람 화면은 실제 한국 시간). 바꾼 뒤에는 그 시각부터 평소처럼 흐른다.
- 개발 모드 첫 로드는 컴파일 때문에 1분 넘게 걸릴 수 있다(로그인 뒤 "숲을 불러오는 중…" 이 길게 보임).

- [ ] DEV 패널 버튼과 주소 옵션으로 시작·빈터·오두막에 바로 가고, 구역 이름이 산길·숲의 빈터·산길(앞마당)로 맞다. (FEAT-15)
- [ ] 시간 버튼·`time` 옵션으로 낮·밤이 바뀌고, [지금] 으로 실제 시간에 돌아온다. (FEAT-15)
- [ ] 배포용 빌드에서는 DEV 패널이 보이지 않는다. (FEAT-15)

스크린숏과 콘솔 기록은 저장소의 `.screenshots/`(git에서 뺌)에 저장된다. (BUG-06)

## 회귀 테스트 우선순위

시간이 없을 때는 다음 순서로 확인한다.

1. 로그인 → `/forest` 진입
2. 걷기/시점/충돌
3. 계단 → 2층
4. 앉기/일어나기
5. 두 탭 채팅
6. 장작 → 불
7. 콘솔 오류/CSP

## 버그 리포트에 포함할 것

- 브라우저/OS/기기
- 재현 절차(좌표/존 포함)
- 콘솔 오류와 네트워크 상태
- `/healthz` 응답
- 스크린샷 또는 짧은 화면 녹화
