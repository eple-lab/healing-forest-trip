# 13 · 검증 체크리스트

## 자동 검사

```powershell
npm.cmd run typecheck   # tsc --noEmit
npm.cmd run lint        # ESLint (선택)
npm.cmd run build       # next build
```

빌드 시 `NEXTAUTH_SECRET` 경고는 로컬에서 정상이다(운영에서는 필수).
배포 전에는 반드시 typecheck 와 build 를 모두 통과시킨다.

커밋할 때마다 pre-commit 훅(`.githooks/pre-commit`)이 0번(개인정보) 검사를 한다. 클론마다 한 번 켠다. (BUG-06)

```powershell
git config core.hooksPath .githooks
```

막히면 `--no-verify`로 넘기지 말고 고친다. 진짜 이름이 아닌 정해진 값만 `.githooks/allow-patterns`에 예외로 적는다.

## 수동 스모크 테스트

### A. 랜딩과 인증

- [ ] `/` 에서 숲 소개/통계/로그인 버튼이 보인다.
- [ ] 게스트 닉네임 1자 → 오류 안내.
- [ ] 게스트 닉네임 2~16자 → `/forest` 진입.
- [ ] Google 설정 시 Google 버튼 → 동의 → `/forest`, 이름/사진 표시.
- [ ] Google 설정이 없으면 Google 버튼이 보이지 않는다.
- [ ] 로그아웃 → `/` 로 돌아가고 세션이 사라진다.
- [ ] `?callbackUrl=https://evil.example` 같은 값으로 오픈 리다이렉트가 되지 않는다.
- [ ] 들어가기 화면에 내 모습이 보이고, [모습 바꾸기]로 바꾼 뒤 들어가면 바뀐 모습이다. (FEAT-04)
- [ ] 새로고침해도 바꾼 모습이 남는다. (FEAT-04)

### B. 이동과 시점

- [ ] 시작 지점에서 남쪽(빈터 방향)을 바라본다. (FEAT-02)
- [ ] `W/A/S/D` 와 방향키가 모두 동작한다.
- [ ] 마우스 클릭 후 포인터가 고정되고 위/아래/좌/우 시점이 된다.
- [ ] `Esc` 로 포인터 고정이 해제된다.
- [ ] `Shift` 로 달리면 빨라지고 FOV 가 살짝 넓어진다.
- [ ] 나무/오두막 벽/가구에 끼지 않고 미끄러진다.
- [ ] 경계(`x ±86`, `z -225~105`)를 벗어나지 않는다.
- [ ] 계단을 걸어서만 2층에 오른다(순간이동 없음).
- [ ] 2층 난간/구멍에서 떨어지지 않는다.

### C. 앉기/눕기

- [ ] 그루터기 근처에서 `E · 그루터기에 앉기` 프롬프트.
- [ ] 앉으면 시점이 낮아지고 호흡 흔들림이 있다.
- [ ] `E` 또는 이동 키로 일어난다.
- [ ] 빈터 통나무 벤치 5곳에서 앉을 수 있다.
- [ ] 흔들의자에 앉으면 앞뒤로 천천히 흔들린다.
- [ ] 2층 창가 좌석에서 앉아 하늘을 본다.
- [ ] 침대에서 눕기 → "쉬는 중" 오버레이 → 일어나기.
- [ ] 그루터기, 벤치, 흔들의자, 1층 의자, 2층 큰 창가, 침대에서 각각 일어난 뒤 W·A·S·D로 바로 걸을 수 있다. (BUG-01)
- [ ] 1층에 있을 때 2층 대상(큰 창가, 침대)의 알림이 뜨지 않는다. 2층에 올라가면 뜬다. (BUG-02)

### D. 상호작용

- [ ] 표지판에서 읽기 프롬프트와 문구.
- [ ] 오두막 앞 표지판 문구가 열린 문과 맞다. (BUG-04)
- [ ] 화덕 근처에서 손 녹이기 + 온기 효과.
- [ ] 장작더미에서 장작 줍기 → 1인칭 장작 표시.
- [ ] 벽난로에 장작 넣기 → 불 세기/소리 증가, 다른 탭에도 반영.
- [ ] 장작 없이 벽난로 → 안내 토스트, 변화 없음.
- [ ] 담요 테이블에서 담요 집기 → 앉아서 덮기 → 자세/색 반영.
- [ ] 냉장고/커피포트/싱크대에서 물/커피 → 머그 표시 → 4.2초 후 사라짐.
- [ ] 빈터 밖에서 채팅 시도 → "빈터에서만" 안내.

### E. 멀티플레이어

- [ ] 두 탭(또는 두 브라우저)에서 서로의 캐릭터가 보인다.
- [ ] 원격 캐릭터가 부드럽게 이동하고 걷기/앉기 자세가 반영된다.
- [ ] `players:move` 배열이 오고 `player:move`(단수)는 오지 않는다.
- [ ] 이름표가 표시되고 게스트는 "나그네" 로 보인다.
- [ ] 접속/퇴장 토스트가 뜬다.
- [ ] 빈터에서 채팅 → 빈터의 다른 사람에게만 보인다.
- [ ] HUD 인원/존 표시가 갱신된다.
- [ ] 네트워크를 끊었다 켜면 자동 재접속되고 상태가 복구된다.
- [ ] 40명 정원/탭 9개 초과 시 거부 안내(가능하면).

### F. 시간과 분위기

- [ ] HUD 시간이 한국 시간과 맞는다.
- [ ] 밤에는 별/달/반딧불이, 낮에는 해/나비가 보인다.
- [ ] 오두막 안이 밖보다 따뜻한 조명이다.
- [ ] 벽난로 불빛이 벽/가구에 반영된다.
- [ ] 2층 큰 창으로 하늘/숲/새가 보인다.
- [ ] 밤에 다른 탭으로 10초 이상 갔다 돌아오면 반딧불이가 계속 움직인다. (BUG-03)

### G. 사운드

- [ ] 시작 오버레이 전에는 소리가 없다.
- [ ] "숲으로 들어가기" 후 바람/새소리가 들린다.
- [ ] 걷기/달리기에 발소리가 나고 표면에 따라 질감이 다르다.
- [ ] 발소리가 작고 부드럽다. 바람 소리와 새소리는 이전과 같다. (FEAT-01)
- [ ] 실내/야간에 믹스가 달라진다.
- [ ] `M` 또는 버튼으로 음소거가 즉시 적용된다.
- [ ] 새로고침 후 다시 제스처 전에는 소리가 없다.

### H. UI/접근성

- [ ] HUD 에 시간/존/인원/연결 상태가 보인다.
- [ ] `H` 로 도움말, `Esc` 로 닫기.
- [ ] `Enter` 로 채팅 열기, `Esc` 로 닫기, 전송 후 스크롤.
- [ ] 토스트가 `aria-live` 로 읽힌다.
- [ ] 모든 버튼에 포커스 링/`aria-label`.
- [ ] 모바일 세로/가로에서 HUD 가 겹치지 않는다.
- [ ] `prefers-reduced-motion` 에서 과한 애니메이션이 없다.
- [ ] 입구 알림판의 제목 띠와 종이 영역이 나뉘어 보이고 글자가 또렷하다. (FEAT-03)

### I. 보안

- [ ] 응답 헤더에 CSP/HSTS/X-Frame-Options 가 있다.
- [ ] 콘솔에 CSP 위반이 없다.
- [ ] 채팅에 `<script>` 를 넣어도 텍스트로 표시된다.
- [ ] 채팅 240자 초과가 잘린다.
- [ ] 1.5초 내 연속 전송이 거부된다.
- [ ] 빈터 밖에서 소켓 `chat:send` 를 직접 보내면 거부된다.
- [ ] `move` 에 `NaN`/거대 좌표를 보내도 서버가 clamp 한다.
- [ ] 잘못된 Origin 의 소켓 연결이 거부된다.
- [ ] 저장소 전체 `git grep`에 PC 사용자 폴더 경로·메일·키·토큰이 0건이다(예시 값 제외). (BUG-06)

### J. DB/운영

- [ ] `DATABASE_URL` 설정 시 `/healthz` 의 `db: true`.
- [ ] 재시작 후 최근 채팅 30건과 불 상태가 복원된다.
- [ ] `/api/stats` 가 숫자를 반환한다.
- [ ] `db:migrate` 재실행이 오류 없이 끝난다.
- [ ] `db:prune` 이 삭제 건수를 출력한다.

### K. 브라우저 종료와 오류 화면

- [ ] 한 탭을 닫으면 남은 탭의 HUD 인원이 즉시 1명 줄어든다.
- [ ] 탭 종료 후 `/healthz` 의 `players` 가 감소한다.
- [ ] 네트워크를 끊으면(개발자도구 → Network Offline) 최대 20초 안에 인원이 준다.
- [ ] 브라우저 종료 후 다시 열어도 자동 로그인되지 않는다(세션 쿠키가 없다).
- [ ] React 오류가 나면 한국어 오류 화면("화면을 불러오지 못했습니다")이 뜬다.
- [ ] WebGL `contextlost` 시 복구 안내가 뜨고, 새로고침 후 정상 동작한다.
- [ ] 숨겨진 탭에서는 프레임루프가 멈춘다(GPU 사용량 0).
- [ ] `/api/auth/callback` 요청이 10분 60회를 넘으면 429 가 반환된다.

## 자동 회귀 스크립트

로컬 서버(`npm run dev`)가 켜져 있을 때 실행한다.

```powershell
node scripts/smoke-visual.mjs   # 랜딩/로그인/걷기/도움말/채팅/모바일 화면 + 콘솔 오류 수집
node scripts/smoke-two.mjs      # 2탭 접속·이동(players:move 배치)·즉시 퇴장 확인
```

스크린숏과 콘솔 기록은 저장소의 `.screenshots/`(git에서 뺌)에 저장된다. (BUG-06)

## 회귀 테스트 우선순위

시간이 없을 때는 다음 순서로 확인한다.

1. 로그인 → `/forest` 진입
2. 걷기/시점/충돌
3. 계단 → 2층
4. 앉기/일어나기
5. 두 탭 채팅
6. 장작 → 불
7. 콘솔 오류/CSP

## 버그 리포트에 포함할 것

- 브라우저/OS/기기
- 재현 절차(좌표/존 포함)
- 콘솔 오류와 네트워크 상태
- `/healthz` 응답
- 스크린샷 또는 짧은 화면 녹화
