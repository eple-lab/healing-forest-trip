# 02 · 공간과 상호작용

## 1. 산길 초입

- 시작 좌표: `(0, 72)`, 바라보는 방향: 남쪽(`yaw = π`)
- 표지판: "숲속여행 · 산길 초입. 천천히 걸어가세요."
- 잘린 나무 밑동 6개가 길을 따라 놓여 있다. 근처에 가면 `E · 그루터기에 앉기`.
- 앉으면 카메라가 낮아지고 호흡에 맞춰 미세하게 흔들린다. 다시 `E` 로 일어난다.

## 2. 숲의 빈터 (z ≈ -62, 반경 23m)

- 가운데 화덕과 불꽃, 주변에 통나무 벤치 5개.
- 랜턴 줄이 빈터를 감싸고, 낮에는 나비가, 밤에는 반딧불이가 돈다.
- **대화는 이곳에서만 가능하다.** 다른 존에서 `Enter` 를 눌러도 입력이 비활성화된다.
- 벤치에 앉으면 불 쪽을 바라본다.
- 화덕 근처에서 `E` → "따뜻한 기운이 손끝까지 번진다" + 화면 온기 효과.

## 3. 오솔길

- 빈터를 지나 오두막까지 이어지는 굽은 길. 경사와 나무 충돌이 있다.
- 길을 벗어나면 풀/이끼 지형을 걷는다. 발소리 질감이 바뀐다.

## 4. 숲속 오두막 (z -147 ~ -157)

### 1층

| 오브젝트 | 위치 | 상호작용 |
| --- | --- | --- |
| 벽난로 | 왼쪽 벽 `(-4.9, -152.4)` | 장작이 있으면 넣기, 없으면 안내 |
| 흔들의자 | `(-2.75, -152.3)` | 앉기, 담요 덮기/걷기 |
| 담요 테이블 | `(-2.5, -150.1)` | 담요 집기/내려놓기 |
| 주방 상판 | 뒷벽 `(-3.05~2.15, -156.85~-156.05)` | 냉장고(물), 커피포트(커피), 싱크대(물) |
| 장작더미 | 밖 `(6.5, -150.6)` | 장작 줍기/내려놓기 |
| 현관 데크 | `z -147 ~ -144.2` | 매달린 등, 계단 2칸 |

### 2층

| 오브젝트 | 위치 | 상호작용 |
| --- | --- | --- |
| 침대 | `(-2.6, -154.85)` | 눕기, "쉬는 중" 오버레이 |
| 큰 창문 | 앞벽 `z=-147`, 폭 4.8m | 창가 좌석에 앉아 하늘 보기 |
| 창가 좌석 | `(0.2, -147.65)` | 앉기 |
| 협탁/스탠드 | 침대 옆 | 은은한 조명 |
| 러그 | `(-2.3, -151.4)` | 장식 |

계단은 `x 3.34~4.78`, `z -147.15~-151.7` 에 있고, 2층 바닥에는 계단 구멍이 뚫려 있다.
`groundAt` 이 발 높이에 따라 1층/계단/2층 후보를 고르므로, 1층에서 2층으로
순간이동하지 않는다.

## 5. 상호작용 규칙

1. 대상과의 거리 + 시선 방향(dot > -0.25)으로 가장 가까운 하나를 고른다.
2. HUD 하단에 `E` 키 프롬프트와 설명이 뜨고, 대상 위치에 링/글로우가 표시된다.
3. `E` 또는 `Enter` 로 실행한다. 모바일은 오른쪽 아래 E 버튼.
4. 앉은 상태에서는 `E` 가 "일어나기"로 바뀐다. 이동 키를 눌러도 일어난다.
5. 채팅/도움말이 열려 있으면 상호작용과 이동이 멈춘다.

## 6. 상태 전이

```
걷기 ──E(좌석)──▶ 앉기 ──E/이동──▶ 걷기
                   │
                   ├─ 담요 덮기 ──▶ 앉은 채 담요
                   └─ 침대: 눕기 ──▶ 쉬는 중 ──▶ 일어나기

장작 줍기 ──▶ 장작 들기 ──E(벽난로)──▶ 불 세기 증가(서버)
커피/물 ──▶ 1인칭 머그 ──4.2초──▶ 자동 종료
```

## 7. 실패/예외 처리

- 벽난로에 장작 없이 상호작용 → 토스트 안내, 불 변화 없음.
- 빈터 밖에서 채팅 전송 → `chat:denied(clearing_only)` + 토스트.
- 불이 이미 최대 → `fire:full` + 토스트.
- 서버 연결 끊김 → HUD 상태 변경, 자동 재접속. 원격 플레이어 목록 초기화.
