# 02 · 공간과 상호작용

## 1. 산길 초입

- 시작 좌표: `(0, 72)`. 원형 길의 맨 북쪽 끝이고, 고리 안쪽(남쪽, `yaw = 0`)을 바라본다.
- 표지판: "숲속여행 · 산길 초입. 천천히 걸어가세요."
- 양쪽 길 입구의 화살표 표지판: 왼쪽(-x) `← 숲의 빈터`(빈터 갈림길까지 약 127m), 오른쪽(+x) `오두막 →`(오두막 갈림길까지 약 223m). 왼쪽·오른쪽은 시작 지점에서 고리 안쪽을 보고 섰을 때 기준이다.
- 잘린 나무 밑동 6개가 원형 길을 따라 놓여 있다. 근처에 가면 `E · 그루터기에 앉기`.
- 앉으면 카메라가 낮아지고 호흡에 맞춰 미세하게 흔들린다. 다시 `E` 로 일어난다.

## 2. 숲의 빈터 (`(-25, -32)`, 반경 23m)

- 원형 길 왼쪽(-x)의 갈림길(양면 이정표 "숲의 빈터 / 쉬어가는 곳")에서 약 13m 들어간다. 입구는 빈터의 -x 쪽이고, 벤치는 그 입구를 비워 둔다.

- 가운데 화덕과 불꽃, 주변에 통나무 벤치 5개.
- 랜턴 줄이 빈터를 감싸고, 낮에는 나비가, 밤에는 반딧불이가 돈다.
- **대화는 이곳에서만 가능하다.** 다른 존에서 `Enter` 를 눌러도 입력이 비활성화된다.
- 벤치에 앉으면 불 쪽을 바라본다.
- 화덕 근처에서 `E` → "따뜻한 기운이 손끝까지 번진다" + 화면 온기 효과.

## 3. 원형 길

- 숲을 한 바퀴 도는 굽은 길(한 바퀴 약 620m, 걸어서 약 2.5분). 끊김 없이 계속 걸을 수 있고, 바깥쪽으로 숲이 이어진다.
- 갈림길 두 곳에 양면 이정표가 있어 어느 쪽에서 와도 읽힌다(`E` 로 읽기, 3.5m).
- 길을 벗어나면 풀/이끼 지형을 걷는다. 발소리 질감이 바뀐다.

## 4. 숲속 오두막 (중심 `(12, -152)`, 정면은 북쪽 +z)

- 원형 길 오른쪽(+x)의 갈림길(양면 이정표 "오두막 / 불을 피우고 쉬어가세요")에서 약 42m 들어가 앞마당 쪽에서 문으로 다가간다.
- 아래 표의 위치는 **오두막 중심 기준 로컬 좌표**다(월드 좌표 = 로컬 + 오두막 중심). `src/lib/world.ts` 의 `*_LOCAL` 값과 같다.

### 1층

| 오브젝트 | 위치 (로컬) | 상호작용 |
| --- | --- | --- |
| 벽난로 | 왼쪽 벽 `(-4.43, -0.4)` | 장작이 있으면 넣기, 없으면 안내 |
| 흔들의자 | `(-2.28, -0.3)` | 앉기, 담요 덮기/걷기 |
| 담요 테이블 | `(-2.5, 1.9)` | 담요 집기/내려놓기 |
| 주방 상판 | 뒷벽 `(-3.05~2.15, -4.85~-4.05)` | 냉장고(물), 커피포트(커피), 싱크대(물) |
| 장작더미 | 밖 `(6.5, 1.4)` | 장작 줍기/내려놓기 |
| 현관 데크 | `z 5 ~ 7.8` | 매달린 등, 계단 2칸 |

### 2층

| 오브젝트 | 위치 (로컬) | 상호작용 |
| --- | --- | --- |
| 침대 | `(-2.6, -2.85)` | 눕기, "쉬는 중" 오버레이 |
| 큰 창문 | 앞벽 `z=5`, 폭 4.8m | 창가 좌석에 앉아 하늘 보기 |
| 창가 좌석 | `(0.2, 4.35)` | 앉기 |
| 협탁/스탠드 | 침대 옆 | 은은한 조명 |
| 러그 | `(-2.3, 0.6)` | 장식 |

계단은 로컬 `x 3.34~4.78`, `z 4.85~0.3` 에 있고, 2층 바닥에는 계단 구멍이 뚫려 있다.
`groundAt` 이 발 높이에 따라 1층/계단/2층 후보를 고르므로, 1층에서 2층으로
순간이동하지 않는다.

## 5. 상호작용 규칙

1. 대상과의 거리 + 시선 방향(dot > -0.25)으로 가장 가까운 하나를 고른다.
2. HUD 하단에 `E` 키 프롬프트와 설명이 뜨고, 대상 위치에 링/글로우가 표시된다.
3. `E` 또는 `Enter` 로 실행한다. 모바일은 오른쪽 아래 E 버튼.
4. 앉은 상태에서는 `E` 가 "일어나기"로 바뀐다. 이동 키를 눌러도 일어난다.
5. 채팅/도움말이 열려 있으면 상호작용과 이동이 멈춘다.

## 6. 상태 전이

```
걷기 ──E(좌석)──▶ 앉기 ──E/이동──▶ 걷기
                   │
                   ├─ 담요 덮기 ──▶ 앉은 채 담요
                   └─ 침대: 눕기 ──▶ 쉬는 중 ──▶ 일어나기

장작 줍기 ──▶ 장작 들기 ──E(벽난로)──▶ 불 세기 증가(서버)
커피/물 ──▶ 1인칭 머그 ──4.2초──▶ 자동 종료
```

## 7. 실패/예외 처리

- 벽난로에 장작 없이 상호작용 → 토스트 안내, 불 변화 없음.
- 빈터 밖에서 채팅 전송 → `chat:denied(clearing_only)` + 토스트.
- 불이 이미 최대 → `fire:full` + 토스트.
- 서버 연결 끊김 → HUD 상태 변경, 자동 재접속. 원격 플레이어 목록 초기화.
