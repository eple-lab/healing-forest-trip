# 21 · 방위 기준

숲속여행의 방위(동서남북)와 좌표 기호를 하나로 맞추는 기준 문서다.
문서·이슈·주석에서 방향을 적을 때, 지도(FEAT-07)를 그릴 때 이 문서를 따른다.

## 기준 (2026-11-11 확정)

| 방위 | 기호 | 시작 지점에서 고리 안쪽을 보고 섰을 때 | 2D 지도 화면 |
| --- | --- | --- | --- |
| 북쪽 | **-z** | 앞 | 위 |
| 남쪽 | **+z** | 뒤 | 아래 |
| 동쪽 | **+x** | 오른쪽 | 오른쪽 |
| 서쪽 | **-x** | 왼쪽 | 왼쪽 |
| 위 | +y | | |

- 좌표계는 three.js 기본(오른손 좌표계, y 위)이다. 위에서 내려다보면 북쪽(-z)을 위로 둘 때 동쪽(+x)이 오른쪽에 와서 **좌우가 뒤집히지 않는다.**
- 시작 지점 `(0, 72)` 은 남쪽(+z) 끝에 있고, 처음에는 북쪽(-z)을 바라본다.

## 적는 법

- 방위를 쓸 때는 **기호를 같이** 적는다. 예: `북쪽(-z)`, `동쪽(+x)`.
- "왼쪽·오른쪽"은 보는 사람에 따라 바뀌므로, 쓸 때는 기준을 함께 적는다. 예: "시작 지점에서 볼 때 왼쪽(서쪽, -x)".
- 오두막 로컬 좌표(`*_LOCAL`, 오두막 중심 기준)도 축 방향은 같다. 오두막 정면(문·큰 창)은 남쪽(+z)을 향한다.

## 시선 방향(yaw)

앞 방향은 `(-sin yaw, -cos yaw)` 다(`src/components/forest/Player.tsx`).

| yaw | 바라보는 방위 |
| --- | --- |
| `0` | 북쪽(-z) |
| `π/2` | 서쪽(-x) |
| `π` (또는 `-π`) | 남쪽(+z) |
| `-π/2` | 동쪽(+x) |

마우스를 오른쪽으로 움직이면 yaw 가 줄어 시계 방향(북 → 동 → 남 → 서)으로 돈다.

## 주요 장소의 방위

| 장소 | 좌표 | 방위 |
| --- | --- | --- |
| 산길 초입(시작) | `(0, 72)` | 원형 길의 남쪽(+z) 끝 |
| 원형 길 중심 | `(0, -55)` | 남북(z)으로 긴 타원, 반지름 동서 62 · 남북 127 |
| 숲의 빈터 | `(-25, -32)` | 원형 길 안쪽 서쪽(-x). 갈림길은 원형 길 서쪽(-x)에 있고 빈터 입구도 서쪽(-x) |
| 숲속 오두막 | `(12, -152)` | 원형 길 안쪽 북쪽(-z), 살짝 동쪽(+x). 갈림길은 원형 길 동쪽(+x), 정면은 남쪽(+z) |

시작 지점에서 서쪽(-x)으로 돌면 빈터 갈림길이 먼저(약 127m), 동쪽(+x)으로 돌면 오두막 갈림길이 먼저(약 223m) 나온다.

## 2D 지도에 그릴 때

- 화면 오른쪽 = 동쪽(+x), 화면 위 = 북쪽(-z).
- 캔버스처럼 y 가 아래로 커지는 화면이면 `화면x = x`, `화면y = z` 로 그대로 옮기면 된다(z 가 클수록 아래 = 남쪽 +z).
- 수학 그래프처럼 y 가 위로 커지는 화면이면 `화면y = -z` 로 부호를 바꾼다. 바꾸지 않으면 남북이 뒤집힌다.

## 근거

- **해**: `src/lib/time.ts` `sunState` 에서 해는 6시에 +x, 18시에 -x 에 있다. 해는 동쪽에서 떠서 서쪽으로 지므로 동쪽 = +x.
- **관례**: 같은 y-위 오른손 좌표계를 쓰는 Minecraft 는 북쪽 = -z, 동쪽 = +x 다. three.js 로 지도 데이터를 옮기는 MapillaryJS 도 동쪽 = x, 북쪽 = -z, 위 = y 로 바꾼다. three.js 자체에는 방위 규칙이 없으므로 이 문서로 정한다.
- **처음 기획 의도**: 산길 초입에서 숲 안쪽으로 걸어 들어가 오두막에 닿는 여정이라, 시작이 아래(남쪽, +z)이고 오두막이 위(북쪽, -z)인 지도가 자연스럽다.

## 알려진 어긋남

- 낮에 해가 북쪽(-z)으로 조금 기운다(`time.ts` 의 `sz = -0.38`). 한국(북반구)이라면 남쪽(+z)으로 기울어야 한다. 그림자·하늘 빛 방향이 바뀌는 화면 변화라 따로 다룬다.

## 이력

- 처음 문서는 방위가 서로 달랐다. `02-experience`·`06-world` 는 "남쪽을 바라봄(`yaw = π`)"(= 남쪽 +z), `13-testing` 은 "남쪽(빈터 방향)"(= 남쪽 -z)이었다. 앞의 것을 따른 처음 설정(`yaw = π`)은 숲 바깥을 봐서 FEAT-02 로 `yaw = 0` 으로 고쳤다.
- FEAT-06(#14) 문서 작업(`7af7414`)과 주석 수정(`67ac09b`)에서 한때 "-z = 남쪽, -x = 동쪽"으로 적었다. 2026-11-11 이 문서로 "북쪽 = -z, 동쪽 = +x" 로 확정하고 문서를 맞췄다. `67ac09b` 의 커밋 메시지 설명("-z를 남쪽으로 쓰므로 -x는 동쪽")은 틀린 설명이다(주석 내용은 ±x·왼쪽/오른쪽이라 그대로 맞다).
