# 03 · 조작법과 접근성

## 데스크톱

| 입력 | 동작 |
| --- | --- |
| `W` `S` / `↑` `↓` | 앞뒤로 걷기 |
| `A` `D` | 옆걸음 |
| `←` `→` | 제자리에서 왼쪽·오른쪽으로 돌기 (앉아 있어도 일어나지 않음, FEAT-14) |
| `PageUp` `PageDown` | 위·아래 보기 (FEAT-14) |
| `Shift` | 달리기 (FOV가 살짝 넓어짐) |
| 마우스 클릭 | 포인터 고정 |
| 마우스 이동 | 위/아래/좌/우 시점 |
| `E` / `Enter` | 상호작용 · 앉기 · 일어나기 |
| `Enter` (빈터) | 대화 패널 열기 |
| `M` | 소리 켜기/끄기 |
| `H` | 도움말 |
| 오른쪽 위 나가기 버튼(도움말 옆) | 첫 화면으로 나가기(로그아웃, FEAT-16) |
| `Esc` | 대화/도움말 닫기, 포인터 고정 해제 |
| `Backspace`/입력 | 채팅 입력 중에는 이동 키가 동작하지 않음 |

포인터 고정은 브라우저 정책상 **클릭**으로만 요청할 수 있다. 시작 오버레이를 닫은 뒤
화면을 한 번 클릭하면 시점이 고정된다. `Esc` 로 해제할 수 있다.

## 모바일

- 왼쪽 아래 원형 **조이스틱**: 이동. 살짝만 밀어도 천천히 걷는다.
- 오른쪽 화면 **드래그**: 시점 회전.
- **달리기** 버튼: 토글.
- **E** 버튼: 근처 상호작용. 대상이 없으면 비활성.
- 대화/도움말이 열리면 모바일 컨트롤이 숨겨진다.

모바일에서는 포인터 고정을 사용하지 않는다(`pointer: coarse` 감지).
세로 화면보다 가로 화면을 권장한다.

## 상태별 입력

| 상태 | 이동 | 시점 | 상호작용 |
| --- | --- | --- | --- |
| 걷기 | O | O | O |
| 앉기/눕기 | 이동 키로 일어남 | O (제한적) | 일어나기/담요/쉬기 |
| 대화 열림 | X | X | X |
| 도움말 열림 | X | X | X |
| 쉬는 중 | X | X | 일어나기 |

## 접근성

- 모든 버튼은 실제 `<button>` 이며 포커스 링이 보인다.
- 토스트는 `role="status" aria-live="polite"`.
- 토글 버튼은 `aria-pressed`, 아이콘 버튼은 `aria-label`.
- `prefers-reduced-motion` 이면 애니메이션 시간을 0.001ms 로 줄인다.
- 색 대비: 본문 `#eef2e7` / 배경 `#0f1712` (WCAG AA 이상).
- 키보드만으로 로그인 → 시작 → 이동 → 시점 돌리기 → 상호작용 → 채팅이 가능하다.
  시점은 `←` `→`(돌기), `PageUp` `PageDown`(위아래)로 돌린다(FEAT-14). 방향키만으로도 앞뒤로 걷고 돌 수 있다.
- 모바일 safe-area inset 을 HUD/조이스틱에 반영한다.

## 알려진 제약

- iOS Safari 는 WebGL 메모리 제약이 있어 오래 켜 두면 발열이 있을 수 있다.
- 일부 브라우저는 전체화면/포인터 고정을 iframe 안에서 막는다.
- 오디오는 사용자 제스처 전에는 시작되지 않는다(의도된 동작).
- 화면 낭독기는 3D 장면을 읽지 못한다. HUD 텍스트와 도움말로 공간을 설명한다.
